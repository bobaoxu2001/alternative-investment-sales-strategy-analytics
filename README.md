# Alternative Investment Sales Strategy Analytics Platform

**One-line pitch:** An analytics dashboard for alternative investment sales strategy, helping teams identify high-potential investor segments, monitor funnel performance, evaluate regional and strategy-level demand, and prioritize outreach using data-driven insights.

**Author:** Allen Xu

**Live demo:** [Vercel project site](https://alternative-investment-sales-strategy-analytics-matlvkct2.vercel.app/)

**GitHub:** [bobaoxu2001/alternative-investment-sales-strategy-analytics](https://github.com/bobaoxu2001/alternative-investment-sales-strategy-analytics)

> **Data disclosure:** This is a portfolio/demo project built on deterministic synthetic data generated from a fixed random seed. No real client, advisor, investor, fund, or investment-firm data is used. Metrics should be interpreted as a demonstration of the analytics framework, not as real business performance.

## Problem Statement

Alternative investment distribution is relationship-driven, long-cycle, and capital-concentrated. Sales leadership needs to know which advisor segments deserve coverage, where opportunities stall, which strategies are attracting demand, which campaigns create qualified pipeline, and which relationship managers need coaching. Without a unified analytics layer, teams can overvalue activity volume and undervalue conversion quality.

## Solution Overview

This project builds a reproducible analytics workflow from synthetic CRM-style data to dashboard-ready outputs:

1. Generate seven raw tables covering advisors, relationship managers, funds, sales activities, opportunities, campaigns, and campaign engagement.
2. Load the data into SQLite for inspectable relational analysis.
3. Run SQL and Python analysis modules for funnel conversion, RM productivity, product demand, campaign ROI, and advisor priority scoring.
4. Produce processed CSV marts, executive charts, an executive report, and a static portfolio site deployable on Vercel.

## Key Features

- Executive KPI view for expected pipeline, committed capital, conversion rate, campaign spend, average days to close, and high-priority advisors.
- Sales funnel diagnostics by stage, region, firm type, asset class, and AUM segment.
- Relationship manager productivity benchmarking with coaching opportunity flags.
- Product and strategy demand analysis across alternative investment asset classes.
- Campaign ROI module with cost-per-qualified-opportunity and fee-revenue proxy.
- Advisor priority scoring model with tiering and recommended next action.
- Synthetic data disclosure, methodology notes, validation checks, and interview-ready documentation.

## Dashboard Sections

- **Executive Overview:** KPI strip, project context, synthetic data note, and business problem.
- **Analysis Modules:** Interactive tabs for the five analytical modules and their business questions.
- **Selected Visuals:** Executive-ready charts with short insight callouts.
- **Recommendation Summary:** Practical actions for segment prioritization, regional funnel triage, RM coaching, and advisor outreach.
- **Quality and Documentation:** Data model, reproducibility checks, methodology, case study, and interview materials.

## KPIs Tracked

| KPI | Definition |
|---|---|
| Expected pipeline | Sum of expected commitment across opportunities |
| Committed capital | Sum of actual commitment for committed opportunities |
| Funnel conversion rate | Committed opportunities divided by total opportunities |
| Average days to close | Mean close cycle for committed opportunities |
| Campaign ROI % | Fee-revenue proxy less campaign cost, divided by campaign cost |
| Cost per qualified opportunity | Campaign spend divided by due-diligence-or-later opportunities |
| RM productivity | Conversion, engagement, follow-up completion, and commitment per meeting |
| Advisor priority score | Weighted score using engagement, AUM, conversion, product fit, and recency |

## Data Source and Assumptions

The dataset is synthetic and generated by [`src/generate_synthetic_data.py`](src/generate_synthetic_data.py). It contains 400 advisors, 16 relationship managers, 10 funds, 28 campaigns, 7,500 sales activities, 1,500 opportunities, and 1,408 campaign engagement records. The generator uses deterministic seed `42` and creates realistic relationships between AUM segment, firm type, engagement, opportunity stage, and commitment size.

See [`docs/METHODOLOGY_AND_ASSUMPTIONS.md`](docs/METHODOLOGY_AND_ASSUMPTIONS.md) and [`data/data_dictionary.md`](data/data_dictionary.md) for details.

## How to Run Locally

Install Python dependencies and regenerate the analytics outputs:

```bash
python3.11 -m pip install -r requirements.txt
python3.11 src/generate_synthetic_data.py
python3.11 src/build_sqlite_database.py
python3.11 src/run_analysis.py
python3.11 src/create_charts.py
python3.11 src/validate_outputs.py
```

Install Node dependencies for the static site tooling:

```bash
npm install
npm run lint
npm run build
```

Preview the site locally:

```bash
python3.11 -m http.server 8123 --directory site
```

Then open `http://localhost:8123`.

## Build and Deployment Notes

`npm run build` copies the static site from `site/` into `dist/`. `vercel.json` sets Vercel to run that build and serve `dist/` as the output directory. No environment variables or secrets are required.

## Limitations

- The data is synthetic and should not be treated as real investor behavior.
- Campaign ROI uses a simplified 2.5% fee-revenue proxy and directional attribution logic.
- Priority scoring is transparent and rules-based rather than machine-learned.
- The dashboard is a static portfolio artifact, not a live CRM-connected application.
- Regional and segment insights demonstrate analytical reasoning, not production recommendations.

## Future Improvements
