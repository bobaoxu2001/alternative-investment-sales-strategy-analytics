# Demo Script

## 3-Minute Walkthrough

1. Open the live site and start with the headline: this is an alternative investment sales strategy analytics dashboard built on deterministic synthetic data.
2. Point to the KPI strip: expected pipeline, committed capital, conversion, advisor universe, RM count, and high-priority advisors.
3. Explain the business problem: long sales cycles, concentrated advisor value, and the need for RM prioritization.
4. Open the analysis module tabs and describe the five views: funnel, RM productivity, product demand, campaign ROI, and advisor scoring.
5. Scroll to visuals and use one chart to explain how the dashboard moves from metric to insight.
6. Use the recommendation section to show that the project is decision-oriented.
7. Close with the quality section: synthetic data disclosure, deterministic pipeline, validation checks, and documentation.

## Key Message

The project is not claiming real investor data. It demonstrates how to structure and communicate an investment sales analytics workflow in a way that is useful to strategy, analytics, and product stakeholders.
