# Future Improvements

## Add CRM Integration

Connect Salesforce, HubSpot, or another CRM as the source for advisors, accounts, activities, campaigns, and opportunities. Add ownership mapping, account hierarchy handling, and field-level validation.

## Add Real Investor Engagement Data

Ingest email, event, webinar, data-room, website, and meeting engagement signals. Use these to replace the synthetic engagement scores with observed behavior while preserving privacy and access controls.

## Add Cohort Analysis

Track opportunity cohorts by creation month, product, advisor segment, and RM coverage team. Measure stage progression, aging, reactivation, and close velocity over time.

## Add Predictive Lead Scoring

Train a model on historical closed/lost outcomes to estimate conversion probability and expected commitment value. Compare model lift against the current transparent rules-based priority score.

## Add Scenario Modeling

Let sales leaders test coverage and campaign allocation scenarios, such as shifting RM capacity toward high-priority advisors or reallocating campaign budget by channel and segment.

## Add Data Refresh Pipeline

Schedule ingestion, transformation, validation, and dashboard refresh jobs. Add alerts for data freshness, missing feeds, schema drift, and KPI anomalies.

## Add Access Control and Audit Logs

Add role-based access for sales leadership, regional RMs, marketing, and operations. Log data exports, dashboard views, prioritization changes, and model-score usage for governance.

## Synthetic Data Note

The current project uses deterministic synthetic data for portfolio review. These improvements describe how the same analytical framework could mature into a production system using permissioned real data.
