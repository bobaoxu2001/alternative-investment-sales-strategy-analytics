## 100-Word Website Summary

This portfolio project simulates an alternative investment sales strategy analytics workflow. It uses deterministic synthetic data to model advisor coverage, relationship-manager activity, fund demand, opportunities, campaigns, and engagement signals. The dashboard helps reviewers understand how a sales strategy team could identify high-potential investor segments, monitor funnel conversion, evaluate regional and strategy-level demand, benchmark RM productivity, measure campaign efficiency, and prioritize outreach. The project includes Python and SQL pipelines, dashboard-ready CSV outputs, executive charts, validation scripts, methodology documentation, and a Vercel-ready static site. All data is synthetic and public-safe.

## 200-Word Case Study Summary

Alternative investment distribution is long-cycle, relationship-driven, and capital-concentrated. Sales leadership needs more than activity reporting: teams need to understand where the pipeline stalls, which advisor segments generate quality opportunities, how relationship managers convert engagement into commitments, which strategies attract demand, and which campaigns justify additional investment.

This project builds a full analytics workflow around that business problem using deterministic synthetic data. The pipeline generates CRM-style records for advisors, relationship managers, funds, sales activities, opportunities, campaigns, and engagement events. Python and SQL modules transform those records into dashboard-ready marts for funnel conversion, RM productivity, product demand, campaign ROI, and advisor priority scoring. The static dashboard then turns those outputs into recruiter-friendly storytelling: executive KPIs, chart callouts, analysis-module tabs, recommendation cards, quality checks, and documentation links.

The project does not claim real client or investor data. Instead, it demonstrates how an analyst would structure the data model, define KPIs, document assumptions, validate outputs, communicate limitations, and translate analysis into coverage and campaign decisions.
